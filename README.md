# Go Language Server (gopls)

Real-time Go diagnostics, completion, hover docs, and definition navigation via gopls

## Details
- **Identifier**: `matn.ext.go`
- **Version**: `1.0.0`
- **Category**: `languages`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Go Language Server (gopls)**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-go
```
